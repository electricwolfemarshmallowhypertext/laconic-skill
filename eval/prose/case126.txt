In Java, a `HashSet` is a collection that stores unique elements, rejecting duplicate values. It is implemented using a hash table, which provides constant-time performance for basic operations such as add, remove, and contains (on average). Unlike a `TreeMap`, `HashSet` does not maintain an ordering of the elements. Instead, the elements are stored in a hash table and the order of iteration is arbitrary.

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.util.*;

public class WordCount {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String letter = "";
        while (!letter.equalsIgnoreCase("quit")) {
            System.out.print("Enter a letter to search for or 'quit' to exit: ");
            letter = scanner.nextLine().trim();
            if (!letter.matches("[A-Za-z]")) { // validate input
                System.out.println("Invalid input. Please enter a single letter.");
                continue;
            }
            String fileName = "input.txt"; // the name of the text file to read
            Set<String> wordSet = new HashSet<>(); // a set to store unique words
            Map<String, Integer> wordCounts = new HashMap<>(); // a map to store word counts

            try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
                String line;
                while ((line = reader.readLine()) != null) {
                    line = line.replaceAll("\\p{Punct}", ""); // remove all punctuation marks
                    String[] words = line.split("\\s+"); // split the line into words
                    for (String word : words) {
                        if (word.toLowerCase().startsWith(letter.toLowerCase())) { // check if the word starts with the given letter
                            wordSet.add(word);
                        }
                        wordCounts.put(word.toLowerCase(), wordCounts.getOrDefault(word.toLowerCase(), 0) + 1); // update word counts
                    }
                }
            } catch (IOException e) {
                System.err.println("Error reading file: " + e.getMessage());
                System.exit(1);
            }

            List<String> sortedWords = new ArrayList<>(wordSet);
            Collections.sort(sortedWords); // sort the words in alphabetical order
            int totalCount = 0;
            if (wordSet.isEmpty()) {
                System.out.println("No words found starting with " + letter);
            } else {
                System.out.println("Words starting with " + letter.toUpperCase() + ":");
                for (String word : sortedWords) {
                    int count = wordCounts.get(word.toLowerCase());
                    System.out.println(word + " - " + count);
                    totalCount += count;
                }
                System.out.println("Total count: " + totalCount);
            }
        }
    }
}
```

In this modified version of the program, we added input validation to check if a single letter was entered by the user. If the input is invalid, the program will display an error message and prompt the user to enter a valid input again. Additionally, the program also displays a message if no words are found starting with the given letter.
