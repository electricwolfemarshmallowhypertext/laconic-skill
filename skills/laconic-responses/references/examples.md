# Laconic Examples

## Filler removal

Before:

```text
Here's the thing: this matters because the fix is small. Let that sink in.
```

After:

```text
The fix is small.
```

## Process narration removal

Before:

```text
Let me walk you through the deployment steps. First, run npm install. Then run npm test.
```

After:

```text
Run npm install, then run npm test.
```

## Preserve dense answers

Before:

```text
A motherboard connects the CPU, memory, storage, expansion cards, and peripheral ports.
```

After:

```text
A motherboard connects the CPU, memory, storage, expansion cards, and peripheral ports.
```

Short is not enough. The output still has to answer.
